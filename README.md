## Overview

This repository contains one Jupyter notebook plus store and testing CSV files. It records the data exploration and modelling work in a small, reproducible form rather than presenting a deployed application.

## What it does

| Area | Details |
| --- | --- |
| **Data inputs** | Store information and a separate testing dataset. |
| **Notebook workflow** | Data loading, inspection, transformation, and model experiments live in one notebook. |
| **Reproducibility** | The data used by the notebook is stored beside the analysis. |

## Repository map

| Path | Purpose |
| --- | --- |
| `dataStrom4_0.ipynb` | Exploration and modelling notebook. |
| `Store-info.csv` | Store-level source data. |
| `Testing-data.csv` | Evaluation input data. |
